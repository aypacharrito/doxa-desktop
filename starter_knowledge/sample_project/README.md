# CodeAtlas sample project

CodeAtlas is a deliberately small Python project for exercising repository understanding. It scans a folder of Python files and reports file counts, line counts, functions, classes, and TODO markers.

Questions to ask ForgeMind after indexing:

- Explain the architecture of CodeAtlas.
- Where would I add support for JavaScript files?
- Find a possible edge case in `analyzer.py`.
- Write tests for unreadable files.
- Propose a JSON output option without breaking the existing interface.

This project is learning material, not a hidden extension or executable agent tool.
